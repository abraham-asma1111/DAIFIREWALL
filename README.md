 Dynamic AI Firewall - Using Reinforcement Learning
 

A self-learning network firewall using **Reinforcement Learning ** to detect and block cyberattacks in real-time, including **zero-day attacks** it has never seen before.

### Key Features
- ✅ Real-time attack detection using RL agent
- ✅ Zero-day attack detection (behavioral baseline + novelty scoring) 

### Target Customers
- 🏛️ Ethiopian Government (INSA)
- 🏦 Banks (National Bank of Ethiopia, Commercial Bank, Dashen, Awash)
- 💳 Fintech companies
- 📡 Telecom sector
